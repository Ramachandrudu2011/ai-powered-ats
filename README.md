# ATS Backend

This folder contains the backend services for the AI-Powered ATS application.

## Purpose

The backend handles:

- Resume processing
- ATS analysis requests
- API communication
- Server-side application logic

## Technology

- Node.js
- Express.js
- JavaScript

## Running the Server

Install dependencies:

npm install

Start the server:

npm start
