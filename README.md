# AI-Powered ATS

An AI-powered Applicant Tracking System that helps job seekers analyze their resumes and understand how well they match job requirements.

## Features

- Resume upload
- Resume analysis
- ATS score
- Job matching
- Skills analysis
- Dashboard
- Resume report

## Technologies

- React
- Vite
- Node.js
- JavaScript

## Project Structure

- `client` - Frontend application
- `server` - Backend application
